## ◈ quiénes somos

**Interaktive Solutions** es un estudio digital creativo de Mar del Plata 🇦🇷. Ayudamos a emprendimientos y empresas a construir su presencia online: desde la identidad visual hasta el producto final funcionando.

🌐 **Web:** [www.interaktivesolutions.com](https://www.interaktivesolutions.com)

## ◈ qué hacemos

| | Servicio | De qué se trata |
|---|---|---|
| 🎨 | **Diseño web** | Interfaces UX/UI a medida, identidad visual y sistemas de diseño que se sienten propios. |
| 💻 | **Desarrollo** | Sitios, landings, plataformas y apps con React, Next.js, TypeScript y Node.js. |
| 🤖 | **Bots** | Chatbots y automatizaciones (WhatsApp, web, flujos internos) que atienden y venden por vos. |
